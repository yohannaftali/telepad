# OS logos

SVG paths from [Simple Icons](https://simpleicons.org) 16.38.0 (CC0-1.0 data),
recoloured white (`fill="#FFFFFF"`) so the app can tint them in each brand colour.

The logos are trademarks of their respective owners and are used only to
identify which operating system a monitored host runs.

Icons with their own licence in Simple Icons:

| File | Licence |
|---|---|
| `debian.svg` | CC-BY-SA-3.0 — Debian logo © Software in the Public Interest, Inc. |
| `rockylinux.svg` | CC-BY-SA-4.0 — Rocky Enterprise Software Foundation |

Windows uses the Phosphor `windows-logo` glyph (MIT), not a Microsoft asset.
